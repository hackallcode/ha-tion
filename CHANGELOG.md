## [2.0.0] - 2026-09-26
### Полный рефакторинг архитектуры
  - Клиент облачного API вынесен внутрь компонента (async/aiohttp), зависимость от заброшенного пакета `tion` убрана.
  - Единый `DataUpdateCoordinator` вместо N запросов на скан.
  - Настройка через UI (Config Flow) с авто-импортом из configuration.yaml.
  - Сущности сгруппированы в устройства (MagicAir, Breezer) через `device_info`.
  - Оптимистичный UI: команды сразу отражаются в интерфейсе, сверка с облаком — отложенным опросом (облако eventually-consistent).
### Новый функционал (из приложения MagicAir)
  - Станция: авторежим (переключатель), целевой CO₂ (число), PM1/PM2.5/PM10 (если поддерживаются), подсветка.
  - Бризер: вкл/выкл (переключатель + climate), подсветка, ограничение скорости от/до (числа),
    забор воздуха (select, у 4S — 2 положения), ресурс фильтра, наработка, турбо-режим, температуры плат, MAC, прошивка, сигнал.
  - Подсветка ставится через `POST /device/{guid}/settings`; параметры бризера — через `/mode` (полный набор полей обязателен).
  - Звук бризера: переключатель (POST /device/{guid}/settings, поле `sound`).
  - Команды записи сериализуются (lock + перечитывание свежего состояния), иначе почти одновременные команды затирали друг друга.
  - Расписание (по комнатам): переключатель «Расписание» вкл/выкл (`POST /zone/{zone}/schedule?on=`, реверс-инжиниринг мобильного API), кнопка «Применить расписание» (`POST /zone/{zone}/schedule/preset`, ставит is_mode_sync=true), индикатор «Синхронизировано» (is_mode_sync), «Текущий пресет».
  - Отдельный переключатель «Нагреватель» (switch), числа «Скорость» (слайдер 1-6) и «Температура» (слайдер 0-30) у бризера.
### Сервисы
  - `tion.get_presets` / `set_preset` / `delete_preset` и `tion.get_schedule` / `set_schedule` / `delete_schedule` — полный CRUD пресетов и расписаний по зоне (таргет — любое устройство Tion зоны).
  - Формы API (по мобильному приложению): preset edit/delete `?presetId=`; schedule edit `?scheduleId=`, delete `?scheduleid=`; enable `POST .../schedule?on=`; apply `POST .../schedule/preset`.
  - Удаление расписания/пресета в облаке Tion побочно стирает все пресеты зоны — `delete_schedule`/`delete_preset` защищены: снапшот перед удалением и авто-восстановление снесённого (удаляется только целевой объект).
### Исправления
  - Фикс: `is_on` берётся из реального состояния устройства, а не из скорости — смена температуры больше не «воскрешает» выключенный бризер.
